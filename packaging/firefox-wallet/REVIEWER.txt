EpixZone maintains EpixNet and Epix Wallet. The wallet is an independent fork of Keplr Wallet by Chainapsis. Chainapsis does not endorse the fork. The public source links above identify the exact submitted revisions. epix-wallet/NOTICE and LICENSE credit the upstream authors. Sites can use window.keplr and the legacy Ethereum provider flags isKeplr and isMetaMask for compatibility. EIP-6963 wallet discovery reports “Epix Wallet” with the identifier zone.epix.wallet.

The extension exposes a wallet provider to websites. Site connections and signing requests have separate approval prompts. Broad host access also supports navigation checks and EpixNet routing. In EpixNet’s address bar, typing a bare EPIX address navigates directly to its .epix site. The extension redirects a URL only when its host is itself a bare EPIX address. Search-engine queries stay with the selected provider. Proxy, blocking request and native messaging permissions support Tor routing, local node settings and Ledger hardware. Firefox storage and unlimitedStorage hold wallet state locally, idle supports locking, alarms schedule node health checks, and notifications report transaction results. Active tab access identifies the current site, and scripting removes stale provider registrations on upgrade. The full data disclosure in EpixNet/packaging/firefox-wallet/DATA-DISCLOSURE.md describes the external recipients, including requests made before a user approves a signature.

Testing

1. Use a fresh Firefox profile and open the Epix Wallet toolbar button. Check the project and fork attribution before choosing to create or import a wallet. Choose “Create a new wallet”, then “Create new recovery phrase”. Use the newly generated phrase and a disposable password of at least eight characters. Lock and unlock the test wallet. No funds or existing account are needed.
2. From the extracted source archive, run “python3 -m http.server 8765 --bind 127.0.0.1 --directory EpixNet/packaging/firefox-wallet”. Open http://127.0.0.1:8765/review-site.html. Click “Request test signature”, connect the disposable account and compare the approval message with the text on the page. Check that the punctuation and both spaces after the first colon appear unchanged. Click the cancel (×) button next to Approve, then check that the page reports the rejection. The page requests a text signature only.
3. Open Settings and choose “Noble USDN balance and claims”. Check the claim and withdrawal controls with the unfunded account. Open the staking screen separately. The dedicated Noble Earn enrollment, deposit and terms screens have been removed. Open blocklist.html under the extension’s own moz-extension origin and check the bundled tab title, “Epix Wallet”. In ordinary browsing, a phishing-list match opens the hosted warning page at https://blocklist.keplr.app with the matched URL. The bundled title change leaves that redirect in place. The local title check needs no visit to a blocked site.
4. After installing dependencies and building the libraries as described in BUILD.txt, run the signing-preview and Noble account regression tests from epix-wallet:
   yarn workspace @keplr-wallet/extension test --runInBand src/pages/sign/utils/message-preview.spec.ts src/pages/earn/overview/index.spec.tsx

BUILD.txt explains how to reproduce the release and compare each file. EpixNet-specific native host and network routing features require EpixNet. The steps above for wallet setup and signing work in desktop Firefox.
